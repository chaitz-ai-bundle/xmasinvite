# Pre-Christmas Party Invite 🎄

A festive invitation page for our Pre-Christmas Party: Saturday 5th December, from 5 pm.
Dress code: wear a Christmas jumper or wear red.

Open `index.html` in a browser, or host it with GitHub Pages.

To get RSVPs sent straight to you, set `WHATSAPP_NUMBER` and/or `RSVP_EMAIL` near the top of the `<script>` in `index.html`.
